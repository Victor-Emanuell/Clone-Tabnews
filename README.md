A **study project** inspired by [TabNews](https://www.tabnews.com.br) — a Brazilian content platform built for and by developers. The goal is to replicate its core functionality while practicing modern web development concepts such as component-based architecture, routing, automated testing, and CI/CD pipelines.

🔗 **Live at:** [clone-tabnews-lime-rho-98.vercel.app](https://clone-tabnews-lime-rho-98.vercel.app)

## 🚀 Getting started

```bash
# Clone the repository
git clone https://github.com/Victor-Emanuell/Clone-Tabnews.git
cd Clone-Tabnews

# Install dependencies
npm install

# Start development server
npm run dev
```

```bash
# Run tests
npm test

# Run tests in watch mode
npm run test:watch

# Check code formatting
npm run lint:check

# Fix formatting
npm run lint:fix
```
